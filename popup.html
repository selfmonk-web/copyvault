How to use CopyVault
  • Right-click Select any text on a page → right-click → Save to CopyVault
  • 🔗 URL Click the link icon in the header to save the current page's URL instantly
  • Manual Open the extension → paste or type in the top field → press Enter or +
  • Click Click any saved item to instantly copy it back to your clipboard
  • ∨ Expand Click the arrow to expand an item — edit the text, add or remove content, then Save or Cancel
  • 📌 Pin Pin an item to keep it forever — pinned items are never auto-deleted
  • ⠿ Drag Drag items up or down to reorder them however you like
  • ⊞ Window Click the grid icon to open CopyVault in a floating window that stays open while you browse
  • 20 slots Holds up to 20 items — oldest unpinned item drops when full
  • ⚠️ Limits Right-click is unavailable on chrome:// pages, the Chrome Web Store, and the address bar — this is a Chrome security restriction that applies to all extensions
